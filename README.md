# LC-AC108 на Raspberry Pi 4 — локальное распознавание русской речи

Проект автономной голосовой колонки для Home Assistant на Raspberry Pi 4 (2 GB RAM). Этот репозиторий фиксирует проверенную базовую конфигурацию: микрофонный массив LC-Tech RPI_AC108 на кодеке AC108 и локальное распознавание русской речи через Vosk.

> **Текущий статус:** четырёхканальный захват с LC-AC108 и потоковое распознавание русского языка работают. Piper TTS, выполнение команд Home Assistant, wake word и автозапуск голосового приложения пока не настроены.

## Что реализовано и проверено

- Raspberry Pi 4 Model B, 2 GB RAM.
- Raspberry Pi OS 64-bit (Debian 13 Trixie), ARM64.
- LC-Tech RPI_AC108: 4 MEMS-микрофона, аудиокодек X-Powers AC108.
- Обнаружение AC108 по I2C на адресе `0x3b`.
- Сборка и установка модулей `snd-soc-ac108.ko` и `snd-soc-seeed-voicecard.ko` для работающего ядра.
- Пользовательский Device Tree overlay `lc-ac108-4mic-test.dtbo`.
- ALSA capture: 4 канала, `S32_LE`, 16 kHz.
- Сведение четырёх каналов в моно средствами SoX.
- Локальное распознавание русской речи через `vosk-model-small-ru-0.22` в реальном времени.
- Проверка воспроизведения через HDMI-аудио.

## Схема аудиопотока

```text
LC-AC108 (4 MEMS microphones)
        | I2S + I2C
        v
Raspberry Pi 4 / ALSA (4ch, S32_LE, 16 kHz)
        |
        v
SoX (4 channels -> mono, S16_LE)
        |
        v
Vosk (Russian small model)
        |
        v
Recognized text in terminal
```

## Проверенная конфигурация

| Компонент | Проверенное значение |
|---|---|
| Raspberry Pi OS | Debian 13 Trixie, 64-bit |
| Kernel | `6.18.60+rpt-rpi-v8` |
| Python | `3.13.5` |
| ALSA card name | `lc-ac108-4mic` |
| ALSA card ID | `lcac1084mic` |
| Capture | 4 channels, `S32_LE`, 16 kHz |
| ASR model | `vosk-model-small-ru-0.22` |

Номера ALSA-карт и версии ядра могут отличаться на других установках. Подробности и команды диагностики приведены в документации.

## Важно

1. Использованная ветка `pi5` репозитория [avisual/seeed-voicecard](https://github.com/avisual/seeed-voicecard) была собрана на Raspberry Pi 4 с указанным ядром. Это не гарантия совместимости с другими версиями ядра и платами.
2. SHA upstream-коммита, использованного при сборке, не был сохранён. Для воспроизводимой повторной сборки следует отдельно зафиксировать commit SHA.
3. Модель Vosk не включена в этот репозиторий; её нужно получить отдельно и разместить в `~/voice-assistant/models/vosk-model-small-ru-0.22`.
4. Не загружайте `venv/`, модели, WAV-записи, скомпилированные `.ko`, пароли, токены и приватные ключи.
5. Лицензия проекта пока не выбрана. До добавления файла LICENSE не следует считать репозиторий распространяемым под конкретной открытой лицензией.
